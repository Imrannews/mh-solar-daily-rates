# MH Solar Daily Rates ☀️

Flutter Android app for **MH Solar & Electronics** to publish daily solar panel market rates.

## Planned features
- Daily panel, inverter, battery and accessories rates
- Admin rate management with Firebase
- Automatic date/time and last-update information
- WhatsApp, call and share buttons
- Shareable daily rate card
- Push notifications
- Google Play Store release (AAB)

## Development

```bash
flutter pub get
flutter run
```

Package: `pk.mhsolar.dailyrates`
